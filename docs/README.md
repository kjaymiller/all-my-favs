# Documentation

Organized by [Diátaxis](https://diataxis.fr/) — four kinds of docs, each with a different reader and a different shape.

| Section                       | Question it answers                          | When to read |
|-------------------------------|----------------------------------------------|--------------|
| **[Tutorials](tutorials/)**   | "I'm new — guide me through something useful." | Once, when starting out. |
| **[How-to guides](how-to/)**  | "How do I do *X*?"                            | When you have a specific task. |
| **[Reference](reference/)**   | "What are the exact details of *Y*?"          | When you need to look something up. |
| **[Explanation](explanation/)**| "Why is it built this way?"                  | When you want context, not action. |

If a doc starts feeling like two of these at once, split it.
